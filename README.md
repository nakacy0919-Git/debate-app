# Debate App

英語・日本語で主張、理由、具体例、再主張を組み立て、質問と反論に応答するカード式の基礎練習アプリです。React / Vite製。

## 開発・検証

Node.js 24推奨。

```sh
npm ci
npm run dev
npm test
npm run lint
npm run build
```

標準ではタイマーと画像照合はOFF。成績はこのブラウザ内のみ保存し、外部へ送信しません。本名・所在地の入力は不要です。実際のディベート能力を測る試験ではありません。

## 教材

全12テーマとも肯定・否定両立場の主張構築・質問・反論・最終弁論まで対応。**24通りのテーマ×立場について、質問と反論をそれぞれ6種類以上収録**し、1〜6ラウンドの範囲では問題が重複しません。Homework / Tests / Uniforms / Bentoは各立場6ラウンド分、残る8テーマの追加教材は `src/data/extendedRounds.json` に収録しています。

具体例は練習用であり、発表で事実・統計として引用する前に出典を確認してください。

## iPad・タッチ端末

縦画面ではディベート表示と選択肢を上下に配置し、スクロールを独立させます。横画面ではタッチ／Apple Pencil／マウスで左右パネルの仕切りをドラッグして幅を変更できます。キーボード操作では仕切りを選択して左右矢印キーで5％ずつ変更し、Home/Endで最小／最大幅へ切り替えられます。画面の高さには動的ビューポート単位を使用し、タッチ操作領域と画像選択を調整しています。ブラウザでの自動テスト・コード検査は実施済みですが、**実機iPad Safariでの目視・操作確認は別途必要**です。

## セキュリティと公開

[修正内容・検証・本番未反映事項](SECURITY_REVIEW.md)を参照してください。Firestoreへの依存は撤去しました。旧公開アクセスを閉じるための拒否ルールとHostingのセキュリティヘッダーを同梱しています。ルールは対象プロジェクト全体を拒否するため、他のアプリとの共有を確認してから反映してください。

```sh
npm run build
# 対象プロジェクトと共有状況の確認後に実行
firebase deploy --only hosting,firestore:rules
```
